直填版 + 引擎版双方案 · 2026-08-07 构建 · 接口与爬虫逻辑已全部实测通过

type: 3JS 爬虫mp3 直链支持搜索

本配置让你在 影视仓 / TVBox 系 App 里直接听「爱在M站」的歌曲：专辑墙浏览、单曲搜索、专辑内歌单连续播放，播放走 mp3 直链，不需要解析器，也不需要外挂 jar 包。

共两种接入方式：直填版（api 直接指向爬虫 JS，文件最少）和 引擎版（api 指向 drpy2.min.js 引擎 + ext 指向爬虫 JS，饭太硬系配置同款，兼容性最好）。两版爬虫脚本都已用真实接口数据验证通过。

一、工作原理

影视仓加载配置 JSON 后，发现一个 type: 3 的站点，就会把 api 指向的 JS 当爬虫加载。两种模式差异只在「谁在跑爬虫」：直填版由影视仓内置 JS 引擎直接运行 izanmei.js（openlist 项目同款格式）；引擎版由 drpy2.min.js 引擎加载 izanmei_rule.js（规则格式）。爬虫把爱在M站的四个 JSON 接口翻译成影视仓能懂的数据结构：


引擎版 drpy2.min.js + izanmei_rule.js 爱在M站 4 个 JSON 接口 mp3 直链 play.j53.net/song/p/xxx.mp3 播放器直接播放 parse:0 强制直放，不送解析器 detail 返回歌单 爬虫逻辑 ↔ 爱在M站接口： home / 推荐 / 一级 → /album/list 专辑墙（分页） search / 搜索 → /search/song 单曲搜索 detail / 二级 → /album/info · /song/info

三、部署步骤（直填版，3 个文件）

1
托管 izanmei.js
把 izanmei.js 上传到任意静态托管（GitHub/Gitee/cnb.cool/对象存储/网盘直链），拿到直链。
2
改配置并托管
打开 影视仓配置.json，把 "api": "https://你的托管地址/izanmei.js" 换成你的直链，再把 JSON 也传上去，拿到直链。
3
影视仓填入配置地址
影视仓 → 设置 → 配置地址，粘贴 JSON 直链，保存加载。首页出现「爱在M站」→ 专辑 → 歌单 → 播放。

四、部署步骤（引擎版，4 个文件）

1
同目录托管三个文件
把 drpy2.min.js、izanmei_rule.js 放到同一个可访问目录（两个文件必须在同一目录，ext 的加载依赖它），分别拿到直链。
2
改配置并托管
打开 影视仓配置-引擎版.json，把 api 换成 drpy2.min.js 直链、ext 换成 izanmei_rule.js 直链，再把 JSON 托管。
3
影视仓填入配置地址
同直填版第 3 步。如果直填版在你的影视仓版本加载失败，就用这个方案。

⚠️ 用 GitHub raw 链接时，如果电视端访问慢或失败，可在链接前加加速前缀，例如：https://ghproxy.net/https://raw.githubusercontent.com/你的用户名/仓库/main/izanmei_rule.js（加速站可能变化，失效就换一个）。

⚠️ 引擎版依赖说明：drpy2.min.js 取自公开配置仓库 gaotianliuyun/gao 的 lib 目录（饭太硬系定制版），它运行时会从 down.nigx.cn 拉取模板依赖。若日后该依赖失效，需要换一个同样开源的 drpy2.min.js 或改用直填版。

五、接口映射对照

爱在M站接口直填版函数引擎版字段映射要点
/album/list?f=json&page_no=Nhome / category推荐 / 一级mAlbumId→vod_id(ALBUM##id)、mTitle→vod_name、mPicSmall→封面、作者+共N首→备注
/album/info?album_id=IDdetail二级歌单每首「歌名$mp3直链」用 # 连接成 vod_play_url，进详情即可连播整张专辑
/search/song?f=json&q=关键词search搜索mSongId→vod_id(SONG##id)，无图字段留空由客户端兜底
/song/info?song_id=IDdetail二级补全单曲封面（mPicBig）、专辑名、歌手
play.j53.net/song/p/{id}.mp3playlazy直链强制 parse:0 直放（引擎 SPECIAL_URL 不认 mp3，必须走 lazy）

七、常见问题

现象原因 / 处理
站点加载不出来 / 一直转圈① JS 直链电视端访问不了（GitHub raw 被墙）→ 换加速前缀或换托管；② 配置 JSON 语法错误 → 用 JSON 校验工具检查；③ 直填版不被当前版本支持 → 换引擎版（或反之）。
搜索有结果但没封面正常现象。爱在M站搜索接口本身不含图片字段，已留空由客户端兜底，点进单曲详情会补上真实封面。
播放失败 / 没声音① 直链被播放器拒绝 → 影视仓里切换硬解/软解内核；② 源站临时故障 → 稍后再试；③ 播放时被送去解析器（表现为转圈后失败）→ 确认用的是本包配置（直填版 play 直返、引擎版 lazy 强制 parse:0）。
引擎版报 js 相关错误① drpy2.min.js 与 izanmei_rule.js 不在同一目录；② down.nigx.cn 依赖失效 → 换 drpy2.min.js 来源或改直填版。
专辑翻页翻到空白页爱在M站分页接口不返回总页数，爬虫按「有数据就允许下一页」处理，最后一页多翻一次属正常。
想加进自己现有的配置把 sites 数组里对应那条「爱在M站」对象复制进你现有配置的 sites 里即可，无需用本配置文件。
